# ⚡ Simple Optimization Mod

一个轻量级的 Minecraft 1.12.2 模组，为原版游戏带来新的附魔、功能模块和视觉反馈。

---

## 📦 主要功能

### 🧙 自定义附魔系统

新增 **20+ 种** 独特附魔，涵盖武器、盔甲和工具：

| 类别      | 附魔名称                                  |
|---------|---------------------------------------|
| ⚔️ 战斗类  | 暴击几率、暴击伤害、嗜血（低血量增伤）、处决（斩杀低血量目标）       |
| 🛡️ 防御类 | 虚空保护（坠入虚空传送）、飞行（胸甲飞行，消耗饥饿和耐久）         |
| 🔧 工具类  | 物品修复（自动修复耐久）                          |
| 💚 治疗类  | 治疗者（攻击转为治疗）、治愈之刃（伤害+回血）               |
| ⭐ 特殊类   | **无尽之力**（无敌、秒杀、飞行、容器、激光等全能附魔，仅创造模式获取） |

### 🎮 客户端功能模块

通过 GUI（默认 <kbd>RSHIFT</kbd>）管理三个可开关模块：

- **AutoSprint** – 自动疾跑
- **NoFOV** – 锁定视野角度
- **Velocity** – 防击退 / 反击策略

### 💥 伤害指示器

攻击或治疗时显示浮动数字，支持百分比模式、两行显示（伤害 + 生命值），第三人称自身伤害始终可见。

### 🔧 铁砧成本移除

默认取消“过于昂贵”限制，任意附魔成本均可操作（可在配置中关闭或自定义上限）。

### 🧹 移除攻击粒子

默认去除攻击生物时的红色/白色受击粒子，战斗画面更干净。
