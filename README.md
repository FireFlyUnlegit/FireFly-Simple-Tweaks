## 📦 主要功能

### 🧙 自定义附魔系统

新增 **85 种** 独特附魔，涵盖武器、盔甲、工具与弓箭。

#### 🌈 元素系统

8 种元素 —— **物理 / 火焰 / 寒冰 / 雷霆 / 流水 / 自然 / 暗影 / 光辉** —— 各有一个**转化**剑附魔
（EPIC，**八者互斥**）与一个**元素亲和**护甲附魔（= 元素保护，RARE），另有一个**元素精通**（LEGENDARY）：

- **转化**：把命中的一部分（`10% + 每级 5%`，上限 50%）从原伤害中取消，以该元素重新结算，
  并额外追加一半的元素伤害。物理是默认元素 —— 未被其他元素认领的伤害都算物理。
- **元素亲和**：每件护甲每级减少该元素伤害 4%，四件合计最多 80%。
- **元素精通**：让**元素输出**提高每级 10%（上限 +200%，5 级时 +50%）。只放大元素伤害，
  **不给平砍加成**，也**不与任何转化冲突**，可与任意元素搭配。
- **元素反应**：命中会留下元素标记，下一击若为另一种元素则触发反应（单体、18 种组合）。

| 反应 | 组合 | 效果 |
|---|---|---|
| **融化** | 寒冰 → 火焰 | +55% 伤害，目标护甲 −25% |
| **湮灭** | 暗影 ↔ 光辉 | +60% 伤害，失明，攻击者回复 25% |
| **导电** | 流水 ↔ 雷霆 | +35~40% 伤害，**护甲 −40%**（最强破甲） |
| **蒸汽** | 火焰 ↔ 流水 | +40~45% 伤害 |
| **燃烧** | 自然 → 火焰 | +50% 伤害 |
| **消散** | 火焰 → 寒冰 | +45% 伤害，缓慢 |
| **背刺** | 暗影 → 物理 | +55% 伤害 |
| **绽放** | 流水 ↔ 自然 | **零伤害**，重度缠绕 7 秒 |

### 🎮 客户端功能

- **伤害指示器** —— 攻击或治疗时显示浮动数字，支持百分比模式、两行显示（伤害 + 生命值），第三人称自身伤害始终可见
  - **数字只报最终掉血**：显示的是血条实际变化量，不会出现"打了 150 只掉 48"这种误导
  - **按元素上色**：物理 / 火焰 / 寒冰 / 雷霆 / 流水 / 自然 / 暗影 / 光辉 各有独立颜色
  - **可选物理/元素分裂**：同一次命中把两部分拆成两个数字，落在目标中心的左右两侧（位置随机、不跟随实体）
- **附魔图鉴** —— 通过 `/simple_tweaks enchantinfo` 打开，按稀有度分类浏览所有附魔，悬停显示详细信息
- **配置界面** —— 通过 `/simple_tweaks stconfig` 打开，实时修改配置，无需重启
- **附魔名彩色** —— 按稀有度着色，`无尽之力` 为动态彩虹
- **攻击粒子抑制** —— 默认去除受击粒子（可配置）
- **铁砧成本移除** —— 默认取消"过于昂贵"限制（可配置上限）
- **自动冲刺** —— 客户端模块

### 👹 怪物强化

难度不再只是"多刷几只怪"：每个怪在**生成时**按当前难度获得等级，并被本模组强化。
四个开关在 `/simple_tweaks stconfig` 的「怪物」页（配置键 `mobEnhancement.*`）：
`enabled` / `levelsEnabled` / `enchantmentsEnabled` / `elementsEnabled`。

- **等级系统** —— 基础攻防随等级提升（生命、攻击、护甲各自成长），**等级无上限**。
  等级 = 区块"年龄/难度" **+ 玩家整身的强度**（护甲、最大生命、攻击力、全身附魔等级之和），
  所以**开局只有 Lv1~3**，随换装与附魔持续上涨；同一地点刷出的一群怪等级会在一个区间内浮动，
  头顶显示 **`[Lv.N]`** 名牌（服务端算好、同步给客户端）。
  **所有怪物都有等级**——不穿装备的蜘蛛、苦力怕、史莱姆同样按等级加血加攻，而不是只有拿剑的僵尸
- **模组附魔装备** —— 僵尸/骷髅有几率带着**本模组的附魔**武器和混合材质护甲生成。
  附魔强度按**整只怪的总等级预算**给：`1 + 等级/10` 级（Lv1–9 → 1 级，Lv10–19 → 2 级，
  Lv20–29 → 3 级……），预算分摊到它全身的装备上，单件最多 3 条附魔。
  **这些附魔会在掉落时被剥掉**，不会把模组附魔外流给玩家
- **元素攻击与抗性** —— 怪有几率带上攻击元素（命中附带该元素伤害）和元素抗性（随等级提升）
- **苦力怕强化** —— 爆炸威力随等级提升（有上限）
- **难度偏移** —— `/simple_tweaks difficulty <0-100>` 临时抬高基础难度，直接看出等级/附魔/元素
  三条概率的变化；`/simple_tweaks difficulty reset` 归零（**仅本次会话**，不写存档）

- Minecraft **1.21.1**

## ⌨️ 常用命令

所有命令都在 **`/simple_tweaks`** 根下，`/fst` 是等价别名（两者完全一样）。

| 命令                                                | 作用                     | 权限 |
|---------------------------------------------------|------------------------|----|
| `/simple_tweaks enchantinfo`                      | 打开附魔图鉴（`ei` / `enchinfo` 亦可） | 无  |
| `/simple_tweaks stconfig`                         | 打开配置界面                 | 无  |
| `/simple_tweaks enchant <目标> <附魔> <等级> [槽位]`        | 给物品设置附魔，等级 `0` 即移除    | OP 2 |
| `/simple_tweaks difficulty`                       | 查看当前难度偏移与对应平均等级        | OP 2 |
| `/simple_tweaks difficulty <0-100>`               | 临时抬高基础难度（**仅本次会话**）   | OP 2 |
| `/simple_tweaks difficulty reset`                 | 难度偏移归零                 | OP 2 |

> 配置也可以直接改 `config/simple_tweaks.json`；`/simple_tweaks stconfig` 是它的图形界面，
> 改完即时生效，无需重启。
