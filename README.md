# ⚡ FireFly's Simple Tweaks

一个自己做着玩的 Minecraft 模组，为原版游戏带来新的附魔、功能模块和视觉反馈。

## 🌿 版本分支

| 分支                                                                                            | 游戏版本   | 加载器    | 状态     |
|-----------------------------------------------------------------------------------------------|--------|--------|--------|
| [`master`](https://github.com/FireFlyUnlegit/FireFly-Simple-Tweaks/tree/master)               | 1.12.2 | Forge  | ✅ 稳定   |
| [`fabric-1.21.1`](https://github.com/FireFlyUnlegit/FireFly-Simple-Tweaks/tree/fabric-1.21.1) | 1.21.1 | Fabric | 🚧 开发中 |

- 两个版本**平行维护**，不做合并

## 📦 主要功能

### 🧙 自定义附魔系统

新增 **57 种** 独特附魔，涵盖武器、盔甲、工具与弓箭。

#### ⚔️ 战斗类

| 附魔   | 效果                                         |
|------|--------------------------------------------|
| 暴击   | 攻击时概率触发暴击（无需跳跃），等级越高几率越大                   |
| 暴击伤害 | 提升暴击造成的额外伤害                                |
| 双倍暴击 | 暴击时概率造成额外大量伤害                              |
| 嗜血   | 根据攻击者已损失生命值比例提升伤害                          |
| 处决   | 斩杀低生命值目标，阈值随等级提升                           |
| 群攻   | 命中时伤害分摊至周围敌人，总伤害池 = 原始伤害 × 等级，单目标至多承受 100% |
| 连击   | 降低目标受击后的无敌时间，让后续攻击更快生效                     |
| 真伤   | 部分伤害无视护甲                                   |
| 火焰掌控 | 根据目标燃烧时间增伤，命中时延长燃烧并给自己抗火                   |
| 天罚   | 大幅提升最终伤害，命中时削弱目标、定身、压制攻速，降下天雷              |
| 星落   | 箭矢命中后召唤天外陨星追踪目标，撞击引发范围爆炸                   |
| 重力打击 | 根据下落高度提升攻击伤害，有上限，平地跳跃无加成                   |
| 充能打击 | 每次命中储存部分伤害，下一次命中一并释放                       |
| 势能   | 根据与目标的相对移动速度提升伤害，冲刺撞击时最大                   |
| 战斗大师 | 连续命中同一目标累积连击层数，每层提供额外伤害，最高 20%×等级          |
| 刺客   | 斩杀低生命敌人                                    |
| 回响射击 | 箭矢命中后在目标身上再次回响，造成额外伤害                      |
| 快速弓  | 减少拉弓时间，等级越高拉弓越快                            |
| 穿透箭  | 箭矢可穿透多个敌人，命中方块后仍可拾取                        |
| 追踪箭  | 箭矢缓慢转向最近的敌人，范围随等级扩大                        |
| 多重射击 | 每级额外射出一支箭，水平扇形散布，每支箭各消耗一发弹药                |
| 猎手印记 | 箭矢命中给目标打上 10 秒印记，下次任意伤害提升 20%/级            |

#### ⭐ 特殊类

| 附魔       | 效果                                              |
|----------|-------------------------------------------------|
| **无尽之力** | 飞行、无敌、瞬间挖掘、无限食物/耐久、激光攻击、巨量掉落、灵魂绑定等全能能力（仅创造模式获取） |

### 🎮 客户端功能

- **伤害指示器** —— 攻击或治疗时显示浮动数字，支持百分比模式、两行显示（伤害 + 生命值），第三人称自身伤害始终可见
- **附魔图鉴** —— 通过 `/enchantinfo` 打开，按稀有度分类浏览所有附魔，悬停显示详细信息
- **配置命令** —— `/stconfig` 实时修改配置，无需重启
- **附魔名彩色** —— 按稀有度着色，`无尽之力` 为动态彩虹
- **攻击粒子抑制** —— 默认去除受击粒子（可配置）
- **铁砧成本移除** —— 默认取消"过于昂贵"限制（可配置上限）
- **自动冲刺** —— 客户端模块

## 🚀 安装

### 1.21.1 / Fabric

**前置条件**：

- Minecraft **1.21.1**
- [Fabric Loader](https://fabricmc.net/use/) ≥ **0.16**
- [Fabric API](https://modrinth.com/mod/fabric-api) **0.116.17+1.21.1** 或更新
- [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin) **1.12.3+kotlin.2.0.21** 或更新

**步骤**：

1. 从 [Releases](https://github.com/FireFlyUnlegit/FireFly-Simple-Tweaks/releases) 下载 `simple_tweaks-2.0.0.jar`
2. 放进 `.minecraft/mods/`
3. 启动游戏

### 1.12.2 / Forge

**前置条件**：

- Minecraft **1.12.2**
- Forge **14.23.5.2847** 或更新

**步骤**：

1. 从 [Releases](https://github.com/FireFlyUnlegit/FireFly-Simple-Tweaks/releases) 下载最新版
2. 放进 `.minecraft/mods/`
3. 启动游戏
