## 📦 主要功能

### 🧙 自定义附魔系统

**95 种**独特附魔，按稀有度分布：

| 稀有度 | 数量 | 稀有度 | 数量 |
|--------|------|--------|------|
| COMMON（普通） | 7 | LEGENDARY（传说） | 16 |
| UNCOMMON（罕见） | 9 | MYTHIC（神话） | 9 |
| RARE（稀有） | 27 | MYSTERY（神秘） | 2 |
| EPIC（史诗） | 24 | UNIQUE（唯一） | 1 |

#### 🌈 元素系统

8 种元素：**物理 / 火焰 / 寒冰 / 雷霆 / 流水 / 自然 / 暗影 / 光辉**。
每个元素有一个**转化**附魔（EPIC，八者互斥）与一个**元素亲和**护甲附魔（RARE），
另有四个**跨元素**附魔（精通 / 共鸣 / 穿透 / 壁垒）。

- **转化**：把命中的 `1.5% × 等级`（上限 **7.5%**）从原伤害中取消，以该元素重新结算，并额外追加其一半。
  **可附在剑、弓与弩上**——箭矢命中同样触发转化与元素反应。
- **元素亲和**：每件护甲每级减少该元素伤害 4%，四件合计最多 **80%**；八系互不排斥。
- **元素精通**：元素**输出**每级 +10%（上限 **+200%**）；只放大元素部分，不给平砍加成。
- **元素共鸣**：**剧变反应**伤害每级 +10%（上限 **+30%**）；不放大增幅倍率。
- **元素穿透**：无视目标 8%/级（上限 **24%**）的元素减伤。
- **元素壁垒**：受到**任意**元素伤害 −3%/级（上限 **9%**），与单元素亲和**相乘**。
- **元素伤害无视护甲**（八种 `element_*` 伤害类型在 `#minecraft:bypasses_armor` 里）。
- **无敌帧**：元素伤害**不豁免**无敌帧——它属于那一下挥砍。唯一能缩短/取消无敌帧的是**连击**
  （每级 −10%，10 级完全取消）。
- **哪些伤害算元素**：`连锁闪电` 的弧光 = 雷霆、`剧毒` 的毒 tick = 自然、`天界祝福` 的圣光 = 光辉、
  `星落` 的陨星 = 火焰、`回响之盾` 的返还 = 命中你的那个元素。它们都会留下对应元素量。

#### 🧪 高等元素论

- **元素量（附着量）**：元素有量、随时间**线性衰减**：

| 等级 | 元素量 | 存活 | 来源 |
|------|--------|------|------|
| 弱 | 1.0 | 9.5 s | 多数元素命中、闪电弧 |
| 强 | 2.0 | 12 s | 转化 rider、星落、圣光 |
| 超强 | 4.0 | 17 s | 天罚 |

- **附着 ICD（双计数器）**：同一攻击者对同一目标，**2.5 秒**内只有第 1、4、7… 次命中能挂上元素；
  时间窗一过立即重置计数器。毒 tick 与模组自己派发的伤害**绕过** ICD。
- **克制消耗**：水克火、火克冰、冰克水，且水/火/冰/雷克自然——克制时对方元素**消耗翻倍**
  （1 点水吃掉 2 点火）。反应后**先手**残量留下继续衰减，**后手不残留**。
- **增幅反应**（融化 / 蒸发）：不产生独立伤害，直接**乘在触发的那一击上**（×2.0 / ×1.5），
  武器、暴击、精通一起被放大。
- **剧变反应**（感电 / 超载 / 燃烧 / 湮灭 …）：产生**独立伤害**，
  `(4.0 + 等级 × 0.55) × 系数 × (1 + 精通 × 0.08)`；**不吃武器、不暴击**。
  同一目标每 **1 秒**最多吃一次剧变伤害（状态效果不受此限制）。
- **激化**（自然 + 雷霆）：不造成伤害，把目标置入激化状态 6 秒，此后每次自然/雷霆命中附加固定伤害。

| 反应 | 组合 | 类型 | 数值 |
|------|------|------|------|
| **融化** | 寒冰 → 火焰 | 增幅 | **×2.0** |

| **蒸发** | 火焰 → 流水 | 增幅 | **×2.0** |
| **蒸发（反向）** | 流水 → 火焰 | 增幅 | **×1.5** |
| **感电** | 流水 ↔ 雷霆 | 剧变 | 1.25 / 1.15，**护甲 −40%** |
| **超载** | 寒冰 ↔ 雷霆 | 剧变 | 1.60 / 1.50，破甲 / 减速 |
| **燃烧** | 自然 → 火焰 | 剧变 | 1.35 |
| **熄灭** | 火焰 → 自然 | 剧变 | 0.90，减速 |
| **湮灭** | 暗影 ↔ 光辉 | 剧变 | 1.70，失明，攻击者回血 25% |

#### 🛡️ 护甲曲线（超出 20 点不再浪费）

原版把护甲减伤硬封在 20 点（`DamageUtil#getDamageLeft` 里的 `clamp(…, 20.0)`，80% 减伤）。
本模组改成**换一种减伤类型**：

| 护甲 | 行为 |
|------|------|
| `0 … 20` | 原版公式，**逐字节不变**（最高 80%） |
| `> 20` | 百分比维持 80%，**每多 1 点 → 每击固定减伤 0.5**，最多吃掉剩余伤害的 75% |

例（20 点伤害的一击）：护甲 20 → 受 4.0；护甲 26 → 受 1.0；护甲 40 → 受 1.0（封顶）。
100 点伤害的一击：护甲 26 → 受 17；护甲 40 → 受 10。
**玩家与怪物都适用**——高级怪不会因为护甲溢出而变脆。

### 🎮 客户端功能

- **伤害指示器** —— 攻击或治疗时显示浮动数字，支持百分比模式、两行显示（伤害 + 生命值）
  - **只报最终掉血**：显示的是血条实际变化量，不会出现"打了 150 只掉 48"
  - **按元素上色**：8 种元素各有独立颜色
  - **按元素分裂**：同一次命中拆成**每种元素一个数字**（物理 / 流水 / 雷霆 / 反应各一份），
    横向扇形 + **纵向错层**，互不遮挡（位置随机、不跟随实体）
  - **反应浮字**：触发元素反应时在目标头顶显示反应名与它造成的伤害，如 `感电 (-28.30)`
- **附魔图鉴** —— `/simple_tweaks enchantinfo`，可按**稀有度**或**适用物品**两种方式浏览
- **配置界面** —— `/simple_tweaks stconfig`，实时修改，无需重启
- **附魔名彩色** —— 按稀有度着色，`无尽之力` 为动态彩虹
- **攻击粒子抑制 / 铁砧成本移除 / 自动冲刺 / 无受伤镜头震动** —— 均可在配置里开关


### 👹 怪物强化

难度不再只是"多刷几只怪"：每个怪在**生成时**按当前难度获得等级，并被本模组强化。
四个开关在 `/simple_tweaks stconfig` 的「怪物」页（配置键 `mobEnhancement.*`）：
`enabled` / `levelsEnabled` / `enchantmentsEnabled` / `elementsEnabled`。

- **等级系统** —— 基础攻防随等级提升（生命、攻击、护甲各自成长），**等级无上限**。
  等级 = 区块"年龄/难度" **+ 玩家整身的强度**（护甲、最大生命、攻击力、全身附魔等级之和），
  所以**开局只有 Lv1~3**，随换装与附魔持续上涨；同一地点刷出的一群怪等级会在一个区间内浮动，
  头顶显示 **`[Lv.N]`** 名牌（服务端算好、同步给客户端）。
  **所有怪物都有等级**——不穿装备的蜘蛛、苦力怕、史莱姆同样按等级加血加攻，而不是只有拿剑的僵尸
- **模组附魔装备** —— 僵尸/骷髅有几率带着**本模组的附魔**武器和混合材质护甲生成。
  附魔强度按**整只怪的总等级预算**给：`1 + 等级/10` 级（Lv1–9 → 1 级，Lv10–19 → 2 级，
  Lv20–29 → 3 级……），预算分摊到它全身的装备上，单件最多 3 条附魔。
  **这些附魔会在掉落时被剥掉**，不会把模组附魔外流给玩家
- **元素攻击与抗性** —— 怪有几率带上攻击元素（命中附带该元素伤害）和元素抗性（随等级提升）
- **苦力怕强化** —— 爆炸威力随等级提升（有上限）
- **难度偏移** —— `/simple_tweaks difficulty <0-100>` 临时抬高基础难度，直接看出等级/附魔/元素
  三条概率的变化；`/simple_tweaks difficulty reset` 归零（**仅本次会话**，不写存档）

## 🚀 安装

### 1.21.1 / Fabric

**前置条件**：

- Minecraft **1.21.1**
- [Fabric Loader](https://fabricmc.net/use/) ≥ **0.16**
- [Fabric API](https://modrinth.com/mod/fabric-api) **0.116.17+1.21.1** 或更新
- [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin) **1.12.3+kotlin.2.0.21** 或更新

**步骤**：

1. 从 [Releases](https://github.com/FireFlyUnlegit/FireFly-Simple-Tweaks/releases) 下载 `simple_tweaks-2.2.5.jar`
2. 放进 `.minecraft/mods/`
3. 启动游戏

> 该 jar 必须与 CI / 本地 `clean build` 的产物**逐字节相同**（不要重新打包），否则 PCL / Modrinth /
> CurseForge 的指纹识别会认不出它。

## ⌨️ 常用命令

所有命令都在 **`/simple_tweaks`** 根下，`/fst` 是等价别名。

| 命令 | 作用 | 权限 |
|------|------|------|
| `/fst enchantinfo` | 打开附魔图鉴（`ei` / `enchinfo` 亦可） | 无 |
| `/fst stconfig` | 打开配置界面 | 无 |
| `/fst enchant <目标> <附魔> <等级> [槽位]` | 设置附魔，等级 `0` 即移除 | OP 2 |
| `/fst difficulty` | 查看会话偏移 + 持久偏移 | OP 2 |
| `/fst difficulty <0-100>` | 临时抬高基础难度（**仅本次会话**） | OP 2 |
| `/fst difficulty reset` | 会话偏移归零 | OP 2 |
| `/fst difficulty modify <±值>` | 在**计算出的难度**上加一个值，**写入配置文件、重启保留** | OP 2 |
| `/fst difficulty modify clear` | 持久偏移归零 | OP 2 |
| `/fst difficulty check` | 打印 `localDifficulty / base / offset / modify / playerPower → effective → level` | OP 2 |
| `/fst debugItem` | 查看手持物品概要（id / 数量 / 耐久 / 名字 / 组件数） | OP 2 |
| `/fst debugItem nbt show\|set\|add\|remove\|clear` | 编辑 `minecraft:custom_data`（值按 SNBT 解析） | OP 2 |
| `/fst debugItem component list\|get\|set\|remove` | 查看/编辑任意数据组件（走组件自己的 codec） | OP 2 |
| `/fst debugItem enchants show\|copy\|paste\|merge\|set\|remove\|clear` | **复制附魔到另一件物品**：拿 A `copy` → 拿 B `paste`，B 的其它组件不动 | OP 2 |
| `/fst debugItem name\|damage\|unbreakable` | 快速改名字 / 耐久 / 无法破坏 | OP 2 |

> 配置也可以直接改 `config/simple_tweaks.json`；`/fst stconfig` 是它的图形界面，改完即时生效。
